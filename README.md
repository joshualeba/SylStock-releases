# SylStock - Releases

Repositorio publico de instaladores y actualizaciones de **SylStock**, el inventario de escritorio del departamento de sistemas de Sylpack.

- El codigo fuente vive en el repositorio privado `joshualeba/SylStock`.
- Aqui solo se publican el instalador y el paquete ZIP que usa el actualizador de la app.
- La aplicacion consulta este repositorio sin token, por lo que las actualizaciones funcionan en cualquier equipo.

Descarga la ultima version desde la seccion **Releases**.
